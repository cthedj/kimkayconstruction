# KimKay Construction — Website Concept

A responsive multi-page website mock-up for KimKay Construction, Cape Town.

## Pages
- Home
- About Us
- Our Work / Portfolio
- Contact / Project enquiry

## Notes
- Portfolio images are stock photography used for concept purposes.
- Reviews are sample content for the mock-up and should be replaced with verified customer reviews before production.
- Contact details and the enquiry form integration should be connected once confirmed.
- The site is intentionally static so it can be hosted directly on GitHub Pages.

## Preview
GitHub Pages is enabled and deployment is handled by the workflow in `.github/workflows/pages.yml`.
